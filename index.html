DATA GATHERING

🔧

Device Used: Arduino Project

Major Components

Component Purpose
Arduino Uno R3 Main controller that processes sensor data.
DHT11 Sensor Measures temperature and humidity.
RTC Module Provides accurate date and time for each recorded reading.
SD Card Module Allows the Arduino to save the collected data to the SD card.
SD Card Stores the recorded sensor readings for later transfer and analysis.

How it works:

The Arduino gathers data from the sensor and saves each reading into the SD card every second.

General Observation:

Temperature generally increases during the daytime and decreases during nighttime or early morning.

Humidity shows the opposite pattern: it becomes higher when temperature is lower and lower when temperature is higher.

⚠️

POTENTIAL SOURCES OF ERROR:

  • Brownout or power interruption
  • Loose connection
  • Sensor malfunction
  • Missing seconds
  • SD card saving error
  • Sudden weather changes
🛠️

WAYS TO IMPROVE THE PROCESS

  • Use stable power supply
  • Secure all connections
  • Keep the sensor in one fixed location
  • Protect the device from direct rain and sunlight
  • Check all components before recording
  • Record weather observations

SUMMARY OF THE PROCESS

The group collected seven days of temperature and humidity data using an Arduino-based device.


The data were cleaned in R Studio, filtered into hourly records, analyzed, and presented using tables and graphs.
